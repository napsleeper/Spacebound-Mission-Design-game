Space Mission Simulator 
An educational space exploration game developed in Roblox Studio, where players learn how space missions are designed, tested, and controlled.
About the Project
Players explore a space museum, visit testing and mission control rooms, assemble spacecraft, and make engineering decisions involving mass, resources, budgets, and mission planning.

Our goal is to make space science and engineering engaging and accessible to younger audiences through interactive gameplay.
Technologies
- Roblox Studio and Luau (Roblox's Lua-based scripting language)
- NASA mission data as scientific reference
- GMAT (General Mission Analysis Tool) as a reference for orbital mission analysis
- Python and Visual Studio Code during development
- AI-assisted programming with Claude
Source Code
This repository contains 11 Lua scripts extracted from the Roblox project ControlDeMision_v8.rbxlx.

The scripts may be uploaded as individual files. Their original locations are:
- ReplicatedStorage: Educativo.lua, Componentes.lua, Ingenieria.lua, DatosGMAT.lua
- ServerScriptService: ControlDeMision.lua, Campus.lua
- StarterPlayerScripts: ControlDeMisionCliente.lua, PanelRecursos.lua, Cinematica.lua, Consolas.lua, Ensamblaje.lua
Note: The scripts alone are not a playable Roblox game. The original .rbxlx project is needed for the complete game environment and configuration.
Purpose
To encourage curiosity, problem-solving, and interest in STEM by combining interactive space mission gameplay with concepts inspired by real-world exploration.
